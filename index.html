Capabilities

Designed for Stream Processing

Core functionality built directly into a lightweight browser extension architecture.

Stream Detection

Detect supported media streams available on the active browser tab as network requests occur.

Quality Selection

Choose from available stream qualities and resolutions when provided by the underlying source.

Download Manager

Track active download tasks, monitor current progress, and view processing states in real time.

Stream Muxing

Combine compatible media streams into a final unified media file through the supported processing pipeline.

Browser Extension

Designed to work seamlessly inside your browser rather than requiring a separate standalone application.

FAQ

Frequently Asked Questions

Common questions regarding the MixStūra project and the open beta.

What is MixStūra?

MixStūra is an independently developed browser extension designed for detecting supported media streams and downloading/muxing them into standard media containers through its built-in processing pipeline.

Is MixStūra free?

During the current open beta phase, MixStūra is free for all beta testers to use and evaluate.

Is MixStūra still in development?

Yes. The extension is actively undergoing open beta testing. Some features and UI elements are being refined based on user reports and testing results.

Which browsers are supported?

MixStūra is currently targeted for Google Chrome and Mozilla Firefox, subject to active beta builds and platform compatibility.

Where can I report a bug?

Bug reports can be submitted directly on the official GitHub Issues tracker. Please include reproducible steps and browser details.

Where can I suggest a feature?

Feature suggestions and improvements are discussed on GitHub Discussions (Ideas category).
