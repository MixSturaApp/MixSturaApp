# MixStūra

**Video Downloader & Stream Muxer**

MixStūra is an independently developed browser extension designed for detecting supported media streams and downloading/muxing them through a built-in processing pipeline.

---

## Open Beta

MixStūra is currently in open beta testing. The extension is actively being developed and refined.

Feedback, bug reports, and feature suggestions are welcome and help shape the product.

---

## Browser Support

Targeted browsers during the open beta:

* **Google Chrome**
* **Mozilla Firefox**
